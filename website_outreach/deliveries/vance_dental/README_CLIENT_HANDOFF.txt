----------------------------------------------------------------------
1. Go to https://app.netlify.com/drop
2. Drag and drop this unzipped folder into the browser window.
3. Your site will instantly go live with a free SSL (HTTPS) certificate.
4. Click "Domain Management" -> "Add Custom Domain" -> enter "vancedentalstudio.com".
5. In your domain registrar (GoDaddy, Namecheap, Google Domains):
   - Add A Record: @ -> 75.2.60.5
   - Add CNAME Record: www -> [your-site-name].netlify.app
6. You're done! No monthly hosting bills, ever.
